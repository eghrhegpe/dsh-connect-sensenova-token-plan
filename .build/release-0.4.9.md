# 🦝 v0.4.9 — 小浣熊面板按自家设计系统重做，限频与并发两处缺口收口

「小浣熊」tab 原先是三个 tab 里唯一没消费自家设计系统的：注册开关是一个裸 checkbox 加一句脚注长的标签，余额把六件不同性质的事实用间隔号串成一行散文，模型清单的表头替整段说明当标题。这版把它对齐到与「通用积分池」同一套卡片语言。另外修掉限频退避与跨进程写入两处**真实**缺口——都是能自己看出问题的，不是猜测。

---

## 一、小浣熊面板重做

**三个注册开关换成真开关。** 通用提供方、出图工具、小浣熊提供方三处共用一个 `ToggleSwitch`：短标签（「向 DSH 注册」/「注册出图工具」/「启用小浣熊提供方」）加 `title` tooltip 承担说明。原来小浣熊那处是 `启用小浣熊提供方（向 DSH 注册模型）`——标签本身就是一句脚注，读者看到的是一个方框挂在一行散文前面，没有任何东西说「这是个开关」。

开关本体是嵌套 `<div>` 手绘的轨道加滑块（30×17 轨道、12px 滑块、13px 行程），因为本插件不注入样式表，没有 CSS `::before` 可用。隐藏的 `<input type="checkbox">` 不是装饰——键盘焦点、空格切换、以及浏览器自己的 checked 语义都从它来。

**余额从一行散文改成卡片组。** 原来的一行是：

```
余额 12,345.68 · 每日 600 · 奖励 8344 · 月度 0 · 充值 0 · 凭据有效至 21:19 · 续期至 11-02 18:19
```

七件不同性质的事实（一个总额、四个额度分项、两个凭据时钟）挤在一行里，总额被自己撑起来的噪音淹没了。现在：

- 四个分项各一张卡片，放进 `repeat(auto-fit, minmax(min(100%, 110px), 1fr))`——与 `poolsGrid` / `quotas` 同一条响应式规则。110px 是能容纳最长标签「奖励」加数字而不下折行的下限，窄面板自动换列而不是溢出；
- 卡片用 `bg-layer-2` 背景台阶分色，不加第三层边框（外框属于区块卡、内框属于池卡，子卡片靠背景就够）；
- 两个凭据时钟移出余额卡。它们讲的是「这次登录」的到期与续期窗口，不是额度数字。

**凭据时钟与提供方开关归入账号卡。** 这是这版最实质的一处结构调整。原来时钟挤在余额卡里，读者得自己把「登录态」和它的两个时间戳重新拼起来——一个卡里放着关于凭据的疑问，另一个卡里放着凭据的事实。现在账号卡是「已登录 + 退出登录」同行、凭据时钟作状态下注脚、提供方开关直接落在卡片上；余额卡只剩用户第一眼要读的东西。

开关在没登录时仍然可见：「先勾选」「先登录」那两句引导语指的就是它，把控件藏起来等于把指引的落点藏起来。

**模型清单表头去掉机制说明。** 原来表头下面压着「勾选决定哪些模型推送进 DSH 模型列表…」「以下为内置备用模型」两行说明，列表还没开始就先读两段注释。现在表头只剩计数加注册状态徽标，两条说明降到列表底部做脚注，与走势图图例同一层级。读者先看到徽标与列表，读完列表再读到原理。

**开关外那层内缩底色删掉。** 初版把开关包在一层 `bg-layer-2` 的盒子裡，而账号卡自己是 `layer-1`——两层底色叠在一起读起来像一块外来白底压在卡片上，开关反倒成了那块底上的一个小控件。现在开关裸渲染，与另两处开关一致。

## 二、限频与并发

**Retry-After 支持 RFC 7231 的 HTTP-date 形式。** `src/host/sensenova-auth.ts` 此前只认秒数。网关返回 `Sat, 03 Oct 2026 12:00:00 GMT` 这类绝对时间时，退避预算读不到，429 会立刻重试——限频自愈在最需要它的时候静默失效。现在两种形式都认。

**错误响应统一走 `redactedError`。** 八个路由文件（account、api-key、draw、models、provider、raccoon、snapshot）原先各自拼错误消息，其中部分路径会把凭据明文带回响应。现在统一走 `src/host/routes/http.ts` 的 `redactedError`。

**跨进程并发协议补齐两处缺口。**

- `throttle-store` 写入加版本护栏：读到异版的旧值不再覆盖新值。
- `token-store/grant` 改为条件回收：读到别的进程已续期的新 grant 时不再回收。

两处分场景都是「两个进程同时动了同一份状态文件」，单进程测试看不到。

**小浣熊模型描述符不再猜 `contextWindow` / `maxTokens`。** 改为「目录声明为准，缺则交给 harness 决定」。此前硬钉的猜数会让模型声明比网关实际支持的更大，请求落到 400。

**小浣熊面板轮询收敛。** 删掉为追扫码状态而写的补偿轮询，改由服务端状态驱动的双档轮询。客户端不再持有比 walk 活得更久的定时器。
